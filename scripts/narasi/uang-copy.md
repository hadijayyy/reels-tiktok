# Copy: Mereka Menggunakan Uang dengan Cara Berbeda

Naskah dan arahan visual dari user (`scripts/narasi/uang.txt`); kata-katanya tidak diubah. Ending text ditampilkan
sebagai kartu penutup tanpa narasi. Ini cerita perumpamaan, bukan klaim fakta: tidak ada angka atau studi yang
perlu dicek. "Investasi" di sini berarti investasi pada kemampuan diri (buku, kursus, alat kerja), bukan produk
keuangan, jadi tidak ada janji imbal hasil.
